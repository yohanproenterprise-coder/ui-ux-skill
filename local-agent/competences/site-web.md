# Créer un site web vitrine moderne (une page, prêt à publier)

## 1. Cahier des charges (questions courtes)
Objet du site (activité, CV, événement…), nom, slogan, sections voulues (accueil, services, galerie, tarifs,
avis, contact), couleurs ou ambiance, textes et photos disponibles. Si l'utilisateur n'a pas de textes,
rédige-les toi-même et propose-les.

## 2. Construction
Un dossier sites/NOM/ avec index.html (CSS et JavaScript dans le même fichier), responsive (téléphone d'abord) :
- en-tête avec navigation qui se replie en menu sur téléphone ;
- section d'accueil avec un titre fort et un bouton d'action ;
- sections demandées, typographie lisible (system-ui), bonnes marges, contrastes suffisants ;
- images : celles de l'utilisateur (copie-les dans le dossier) ou generate_image pour des visuels d'illustration ;
- formulaire de contact en lien mailto: (aucun serveur nécessaire) ;
- balises title et meta description pour le référencement.

## 3. Vérification
Ouvre le site avec open_item. Fais un screenshot et look_at_image pour vérifier le rendu, corrige ce qui cloche.

## 4. Mise en ligne (gratuite)
Explique la méthode la plus simple : https://app.netlify.com/drop, puis glisser-déposer le dossier du site :
il est en ligne en 1 minute avec une adresse gratuite.
