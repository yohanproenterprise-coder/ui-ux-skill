Questions

Quel ordinateur faut-il ?

Un PC Windows 10 ou 11 (64 bits) avec 8 Go de mémoire conseillés. Pas besoin de carte graphique : elle est utilisée seulement si elle est plus rapide.

Mes photos partent-elles sur internet ?

Non. Tout se fait sur votre PC. Seule la description d'un décor créé par l'IA est envoyée, jamais vos photos.

Comment marche l'essai gratuit ?

L'application est complète pendant 7 jours. Ensuite, collez la clé reçue après l'achat dans « Options » : rien à réinstaller.

Windows affiche un avertissement, est-ce normal ?

Oui, pour les logiciels récents. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
